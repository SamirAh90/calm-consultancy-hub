# Safe Space Showcase

Läs denna "https://hellgrenledarskap.se/" och gör en liknande för den här https://mindtosafety.se/.  Jag har fått denna kommanter från kunden Hej Samir, 

Spontant har jag inte tänkt göra något med hemsidan. Nu är jag nystartad och de flesta som hittar till mig gör det via rekommendationer. Jag är dock medveten om att hemsidan känns basic och inte så rolig. 

Jag tar tacksamt emot ett kostnadsfritt förslag på hur du skulle kunna lägga upp hemsidan. Jag vill ju få fram min spetskompetens men förmedla och sälja trygghet så du ska fokusera på hemsida skappande resten fixar jag
